Mission 9 simulation and hardware rounds, 2020–2022

Simulation round, 2020

The Mission 9 simulation challenge was a rapid object-replacement task over long distances. We built a mother–daughter drone pair. The mothership flew at 20 m/s, so we localized it with RTK GPS. For the daughter drone, I implemented visual SLAM for accurate localization: I fused a 1D lidar with SLAM along the z-axis and tuned ORB-SLAM2's hyperparameters to avoid tracking loss, reducing error by 62.5%. We ran extensive simulations in Gazebo with ROS, and I trained a YOLOv4-tiny model on our own datasets for object tracking. The full simulation was hosted on GzWeb, and localization ran at 23 fps. When results came out in 2021, we were declared world champions of the simulation round.

Hardware round, 2021–2022

I deployed the algorithms on an NVIDIA Xavier NX. The real world varies far more than simulation, so I switched to the full YOLOv4 model and retrained it on our real-world datasets. Localization stayed on ORB-SLAM2 with some fine-tuning. Initial tests ran at only 7 fps; after I optimized inference with TensorRT it reached 15 fps, enough for real-time operation. We also implemented plane segmentation and pose estimation for the target object so the drone could align precisely and perform the replacement.

ICUAS UAV Competition: indoor fire rescue

International Conference on Unmanned Aircraft Systems (ICUAS)
2022

A rescue mission inside a burning building: the drone explores an indoor area, detects an ArUco marker standing in for the fire, and launches a ball of water to put it out. Our solution had three parts: exploration, target tracking and ball launch. Localization used motion capture.

Exploration

The algorithm identifies frontiers, the boundaries between explored and unexplored space, and prioritizes those that maximize coverage with minimal movement, so the drone expands the explored area in a logical order.

ArUco marker detection

Markers are found with contour detection and a set of checks on a processed image that highlights contours, plus a consistency check to reject spurious detections.

Obstacle detection and avoidance

I added real-time obstacle detection to the exploration algorithm using an RGB-D camera. When a collision is likely, the drone reroutes to an alternate path toward the nearest frontier, so exploration continues without interruption.

Waypoint navigation

Waypoints come from the exploration algorithm. Each is an intermediate target based on the current frontiers and ArUco cues, giving precise control over the drone's path.

Communication

Sensors, control and computation are integrated in ROS, with each task running as an independent node.

Academic projects

Satellite image caption generation

B.Tech project (BTP), guide: Prof. Biplab Banerjee
Academic year 2022–2023

The first part of the project was to pick a multimodal problem. I chose satellite image captioning, which can also support image classification. After a literature review I settled on fine-tuning CLIP, one of the best-performing models for the task. I studied the CLIP architecture and fine-tuned it on satellite images by minimizing the contrastive loss, using the Remote Sensing Image Captioning Dataset (RSICD).

In the second part I pivoted to caption generation and scene understanding. I designed a new architecture that extracts hierarchical image features from the CLIP image encoder and projects them into a common space jointly trained with a GPT-2 decoder to minimize contrastive loss; once the weights were learned on satellite images, I used it for caption generation. I grew the dataset by 50% with caption augmentation through the OpenAI GPT API and preprocessed the images (resizing, normalization) to improve training efficiency. I then built a new architecture with CLIP's modified encoder and trained an LSTM decoder for caption generation, starting with the Flickr8k caption dataset.

Medical image caption generator

CS772: Deep Learning for Natural Language Processing, guide: Prof. Pushpak Bhattacharyya
Spring 2023

The goal was to generate concise medical reports from chest X-rays. I used 14k images (224×224×3) from Indiana University Hospital, preprocessed them, and enlarged the dataset with OpenAI paraphrasing and WordNet synonyms for fine-tuning.

The model pairs a Vision Transformer (ViT-patch16-224) encoder with a GPT-2 decoder. In PyTorch, I compared ViT + LSTM against ViT + GPT-2, each with and without fine-tuning on the augmented data. The fine-tuned ViT + GPT-2 model produced the most accurate and realistic reports, especially after augmentation, which improved its grasp of medical terminology. ROUGE bigram scores improved by 20% and F1 by 15%, showing that fine-tuning brings generated reports much closer to actual findings, which matters most in niche domains.

Ensemble attack using linear backpropagation

CS726: Advanced Machine Learning, guide: Prof. Sunita Sarawagi
Spring 2022

Adversarial attacks add perturbations to input data so that a model predicts incorrectly; how the perturbation is built depends on the attacker's access to the victim model. In a black-box setting, the most an attacker sees is the prediction confidence. The aim was a single black-box attack that works against many different victim models.

I combined linear backpropagation with the Momentum Iterative Fast Gradient Sign Method (MI-FGSM) and ran the attack with an ensemble of models. It reached over 80% success against image classifiers such as ResNet, WRN and DenseNet, and 100% against VGG19, substantially improving the transferability of black-box attacks. The same method can be built into training to make prediction models more robust.

Script generator

DS303: Introduction to Machine Learning, guide: Prof. Biplab Banerjee
Spring 2021

The course covered the basics of ML and deep learning and architectures such as CNNs and LSTMs. The project was to generate short script scenes with a fine-tuned GPT-2, in three stages: pretrained GPT-2, GPT-2 trained only on scripts, and GPT-2 fine-tuned on short scripts (the first 300 words of each).

I built it with the Hugging Face library in Python, on a dataset of 60 screenplays from IMSDb with over 25,000 unique words. Given a prompt, the generated scenes were qualitatively good and realistic. The KL divergence of common words was higher in the fine-tuned model, since those words are more frequent in romance, the genre of my dataset.

Quadtree segmentation

GNR602: Advanced Methods in Satellite Image Processing, guide: Prof. Mohan B. Krishna

The goal was to partition images into meaningful regions for applications such as object detection and medical imaging. A quadtree recursively splits an image into four quadrants based on pixel-intensity differences: if a region's difference exceeds a threshold it is split again; otherwise its mean or min/max pixel value is computed and stored.

I implemented the algorithm to adapt to different thresholds and applied it to satellite imagery (finding roads or forests) and medical imaging (locating tumors). The approach is sensitive to shifts and produces variable block sizes, which limits shape analysis and pattern recognition, but it worked well for image compression and for segmenting medical and satellite images.
